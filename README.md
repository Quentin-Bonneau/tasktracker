# TaskTracker #

## About ##

TaskTracker is a simple Java application that helps users manage tasks and practice Java programming concepts.

## Features ##

- Add tasks
- View tasks
- Mark tasks as completed

## Methods ##

| Method | Description |
|---------|-------------|
| main() | Starts the application |
| addTask() | Adds a new task |
| viewTasks() | Displays all tasks |

## How to Compile and Run ##

```bash
javac Main.java
java Main
```
